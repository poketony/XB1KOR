**제노블레이드 크로니클스 Wii**의 한글패치 자료들입니다. 

파일 및 폴더 설명입니다
1. root: 여태까지 작업한 게임 구성 파일들이 들어가 있습니다. 일판 ROM에 그대로 적용하면 잘 작동할 겁니다.
2. REV: 다이나믹 컷신을 한글화하는 작업 공간입니다. 다이나믹 컷신이란 역동적인 그래픽 활용이 들어간 컷신을 의미합니다. 자막이 별도의 폰트로 쓰여집니다.
3. SB: 스태틱 컷신/NPC 대사를 한글화하는 작업 공간입니다. 양이 상상 이상으로 방대합니다. 스태틱 컷신이란 정적이고 일부 고정된 모션만이 쓰이는 컷신을 의미합니다. 자막이 시스템 폰트로 쓰여집니다
4. STATIC: static.arc 파일 한글화에 쓰였던 작업 공간입니다. 작업이 완료돼서 건드릴 필요는 없습니다. static.arc는 게임에서 상시로 활용되는 데이터를 포함하고 있습니다
5. COMMON: common.pkb 파일 한글화에 쓰였던 작업 공간입니다. 작업이 완료돼서 건드릴 필요는 없습니다. common.pkb는 지역별 퀘스트 내용을 담고 있습니다.
6. MAP: map.pkb 파일 한글화에 쓰였던 작업 공간입니다. 작업이 완료돼서 건드릴 필요는 없습니다. map.pkb는 NPC 자동 출력 대사, 물물 교환 대사, 오브젝트 기동 대사 등을 담고 있습니다.
7. MENU: menu.pkb 파일 한글화에 쓰였던 작업 공간입니다. menu.pkb에는 게임 내에 쓰이는 2D 그래픽들이 포함되어 있습니다. 튜토리얼 이미지만 작업하면 될 듯합니다(200장 이상이지만)

pkb/pkh => 게임 콘텐츠 담은 아카이브 파일, pkb는 raw 데이터 이어붙인 것, pkh는 각 데이터 섹션의 이름과 오프셋이 담긴 파일. 따라서 둘이 한 쌍이며, quickbms의 xenoblade pkb ver2.bms로 unpack/repack 가능

.sb => 스태틱 컷신 담당 파일

.rev => 다이내믹 컷신 담당 파일, 암호화 시 .tpl 이미지 확인 가능/복호화 시 대사를 확인할 수 있는 신기한 구조

.bdat => 텍스트 데이터 담긴 파일

.tpl => 이미지 파일 .arc 안에 담겨 있는 경우도 있고 쌩으로 있는 경우도 있고 여튼 BrawlBox로 처리 가능 

메타데이터나 기타 자잘한 부분들은 눈에 보이는 대로 번역해 놓았으니 SB/REV/튜토리얼 이미지만 한글화하면 됩니다. (그 양이 더럽게 많아서 문제지) 
현재 게임의 내부 인코딩은 당연히 원본과 동일한 Shift-JIS입니다. 단지 폰트를 변형시키고 배열을 조작하여 한글을 출력하도록 조작한 것뿐입니다.
Toolkit 안의 Char Changer는 한글을 상응하는 Shift-JIS 한자로 바꿔주는 툴입니다. 작업 후 텍스트 데이터를 복붙하거나 파일을 드래그 드롭한 뒤 원본에 붙여넣어 적용하면 됩니다.
여러모로 유용한 툴이니 다른 게임에서도 사용하면 좋을 듯합니다.
